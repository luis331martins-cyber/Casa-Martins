A pagar

Saldo das contas

Escreve o saldo quando vires o banco. A app calcula quanto deve ficar no fim do mês: saldo + receitas por receber − contas por pagar − o que ainda há para gastar nos gastos do mês.

Adicionar

Adicionar rápido

Colar uma lista de contas ou receitas

Uma por linha: nome; valor; dia. O dia é opcional e o que já existe é ignorado. Uma linha só com “RECEITAS” faz com que as linhas seguintes sejam receitas; “CONTAS” volta às contas.

Tudo se repete todos os meses. Marca as receitas quando entrarem e as contas quando estiverem pagas; o mês seguinte começa do zero. Toca num nome para o editar ou para escrever o valor certo desse mês.
